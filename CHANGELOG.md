# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-12-21

### Added
- Initial release
- SSE-based MCP server for ZFile integration
- Support for file listing (`zfile_list`)
- Support for direct link generation (`zfile_direct_link`)
- Support for short link generation (`zfile_short_link`)
- Docker and Docker Compose deployment support
- Health check endpoint
